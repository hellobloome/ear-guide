# Bloomé Guide — Package 2

Package 2 adds a working, data-driven search engine.

## Included

- Live search across concerns and acupoints
- 12 wellness concern entries
- 14 acupoint entries
- Search aliases such as “insomnia”, “TMJ”, “bloating” and “motion sickness”
- Dynamic result cards
- Related point chips
- Updated safety notice
- Mobile-responsive search results

## Install

1. Extract this ZIP.
2. Copy everything inside the extracted folder into your local `ear-guide` repository.
3. Choose **Replace the files in the destination** when Windows asks.
4. Open GitHub Desktop.
5. Use summary: `Package 2 - Working search engine`
6. Commit to `main`.
7. Click **Push origin**.
8. Wait for GitHub Pages to redeploy.
9. Hard-refresh the live website with `Ctrl + Shift + R`.

## Important

This guide uses cautious, wellness-focused language. It is not a diagnostic or treatment tool.
