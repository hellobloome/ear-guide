## Design rules

- New guides use only existing Bloomé acupoints.
- Each guide remains 4 points or fewer.
- The first point is the Primary point used by Guided Application Mode.
- New guides are not added to the six-card homepage Quick Start area. They are available through Search and Discover.
- Common lifestyle phrases such as "desk reset", "evening wind down" and "study session" are handled as aliases rather than creating unnecessary duplicate pages.
- Wording stays within general wellness / traditional-use framing.

## Package 17

- Primary / Support / Optional ordering
- overlap between similar guides
- 3–5 point simplicity
- related-guide links
