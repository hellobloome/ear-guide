# Package 14 Map Reference

## Mapping approach

Package 14 completes the visual placement of all 30 points in the Bloomé library.

The map uses anatomical auricular descriptions based primarily on the WFAS auricular-point
standardization approach and the Chinese GB/T13734-2008 anatomical subzone system.

The illustration itself remains a simplified Bloomé educational drawing. Marker positions are
therefore visual translations of anatomical zones, not millimetre-precise clinical coordinates.

## Important standardization notes

- **Pancreas and Gallbladder:** WFAS uses a shared **CO11 Pancreas/Gallbladder** zone.
  Bloomé keeps two searchable library entries, so Package 14 shows two close markers inside the
  same shared zone.
- **Subcortex and Thalamus:** source nomenclature can place these references in the inner-antitragus
  **AT4** region. Bloomé shows close markers so each library entry remains selectable.
- **Point Zero:** this is a Nogier-origin point retained from the existing Bloomé map rather than a
  point from the Chinese/WFAS set.

## Safety

Bloomé Guide provides general wellness education. It is not a diagnostic tool or clinical
acupuncture chart, and it does not replace professional medical advice or treatment.
