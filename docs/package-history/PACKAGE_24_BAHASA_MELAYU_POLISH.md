# Package 24 — Bahasa Melayu Polish

Base: Package 23.1 Home Centering Correction.

## Goal
Make the Bahasa Melayu version read naturally and professionally for a Malaysian
consumer audience, instead of feeling like a word-for-word translation.

## What was polished
- Homepage and navigation microcopy
- Search and Discover wording
- Full ear-map interface
- Condition-page labels and guidance
- Guided Application instructions
- Cautions and wellness disclaimers
- All 20 condition names/descriptions/search aliases
- All 30 point names, locations, traditional-use descriptions and stimulation copy
- A few Bahasa Melayu strings generated dynamically in JavaScript

## Language rules used
- Use `anda` consistently.
- Keep `ear seed` as the product term.
- Prefer `tampal` / `tanggalkan` for physical application.
- Prefer natural Malay phrasing over literal translation.
- Reduce unnecessary use of English `reset`.
- Keep anatomical terms such as heliks, antiheliks, tragus, antitragus,
  cavum conchae and cymba conchae where they are useful for point location.
- Preserve wellness-safe wording and avoid treatment claims.
