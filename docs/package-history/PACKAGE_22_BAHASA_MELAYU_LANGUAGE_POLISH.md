# Package 22 — Bahasa Melayu Language Polish

Base: Package 21.1.

## Purpose
Make the Bahasa Melayu interface sound more natural, less literal, and more suitable for Bloomé's Malaysian wellness audience.

## Polished areas
- Homepage heading and supporting copy
- Quick Help
- Discover/search wording
- Ear Map labels
- Condition page instructions
- Guided Application wording
- About / Map Reference explanation
- Condition names, summaries and “Best for” copy
- Selected technical point-location wording where the Malay felt too stiff

## Tone direction
- Human, simple Malay
- Not too clinical
- Not overly formal
- Still cautious and wellness-safe

## Unchanged
- English copy
- Map coordinates
- Occiput placement
- Ear illustration
- Guided Application logic
- Search logic
- Reference codes
