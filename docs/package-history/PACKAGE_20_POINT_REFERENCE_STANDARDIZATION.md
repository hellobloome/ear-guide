# Package 20 — Point Reference Standardization

Base: Package 19.2.

## Scope
This package standardizes the point-reference layer without changing any marker coordinates.

### Added
- Reference codes such as TF4, AT3, CO15, AH5 and LO5 on point pages.
- Small reference-code chips on condition point cards.
- Corrected anatomical location descriptions for standardized points.
- Clear labeling for Point Zero as Nogier-derived.
- Clear labeling for Brain and Thalamus as supplementary references rather than distinct GB/T 13734-2008 standardized points.
- Renamed the user-facing “Lumbar Spine” entry to “Lumbosacral Spine” while preserving lumbar/lower-back search aliases.
- English and Bahasa Melayu reference wording updated together.

### Important
- No map coordinates were changed.
- Package 19.2 Occiput placement is preserved.
- Pancreas and Gallbladder remain separate searchable Bloomé entries but correctly share the CO11 reference zone.

## Primary standard basis
GB/T 13734-2008 — Nomenclature and location of auricular points.
The standard remains current following its 2023 review.
