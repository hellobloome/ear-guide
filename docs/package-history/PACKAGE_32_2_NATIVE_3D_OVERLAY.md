# Package 32.2 — Native In-Site 3D Viewer

Package 32.2 brings the approved 3D ear directly into the main Bloomé Guide.

- View in 3D opens a Bloomé-styled overlay without leaving the guide.
- Closing returns customers to the same map or point page and restores focus.
- The selected point or translucent area is focused automatically.
- The 3D engine, Ear 1 model, and frozen library load only after the first request.
- Package 31.2 2D coordinates, Beta 1B.10 3D coordinates, and Ear 1 geometry are unchanged.
- The separate sandbox is no longer part of the customer journey.
