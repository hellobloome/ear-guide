# Package 32.5 — 3D Location Guidance

Package 32.5 replaces the generic highlight message beneath the selected 3D point with its actual Bloomé location guidance.

- Uses the same location text as the main point library.
- Automatically follows the active English or Bahasa Melayu language.
- Supports all 10 points plus the Occiput and Ear Apex areas.
- Retains the point name, marker, area highlights and camera focus.
- Preserves all frozen coordinates and Ear 1 geometry.
