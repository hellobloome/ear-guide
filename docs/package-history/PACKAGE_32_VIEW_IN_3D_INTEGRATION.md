# Package 32 — View in 3D Integration

Package 32 connects the frozen Package 31.2 Bloomé Guide to the approved Beta 2B 3D viewer.

## Customer experience

- The normal Bloomé Guide remains 2D-first.
- A View in 3D button appears only on the 12 approved point or area pages.
- The 3D viewer opens with the matching location already selected and focused.
- The 3D model is not downloaded during ordinary guide browsing; it loads only after the customer opens the viewer.
- English and Bahasa Melayu button labels are supported.

## Approved 3D locations

Point Zero, Sympathetic, Occiput, Brain, Endocrine, Mouth, Cervical Spine, Shoulder, Adrenal, Subcortex, Thalamus, and Ear Apex.

## Preserved baselines

- Package 31.2 page structure and approved 2D coordinates remain unchanged.
- Beta 1B.10 remains the frozen 3D coordinate baseline.
- Beta 2B remains the standalone 3D viewer baseline.
