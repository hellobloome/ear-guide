# Package 32.1 — Ear Map 3D Shortcut

Package 32.1 makes the 3D experience easier to reach directly from the interactive ear map.

## Changes

- Added View in 3D to the selected-point panel on the full ear map.
- The button appears only for the 12 approved 3D locations.
- Changing the selected map point immediately updates or hides the 3D button.
- The selected location opens directly in its matching Beta 2B guided view.
- Open full point guide remains available as a secondary action.
- English and Bahasa Melayu labels are supported.

## Preserved behavior

- The 2D map remains the default experience.
- The 3D model loads only after View in 3D is opened.
- Package 31.2 2D coordinates and Beta 1B.10 3D coordinates remain unchanged.
