# Package 32.3 — Routine 3D Integration

Package 32.3 brings the native 3D viewer into the concern and guided-application journey.

## Changes

- Added View in 3D beside the selected point on every concern routine page.
- Changing routine tabs immediately updates or hides the button.
- Added View placement in 3D to each supported guided-application step.
- Closing the overlay returns customers to the same concern, selected point, or application step.
- Unsupported points continue normally without an empty or disabled control.
- English and Bahasa Melayu button labels are included.

## Preserved behavior

- The routine remains 2D-first and the 3D model remains lazy-loaded.
- Package 31.2 2D coordinates, Beta 1B.10 3D coordinates, and Ear 1 geometry are unchanged.
