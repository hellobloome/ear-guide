# Package 32.4 — Editorial Ear Makeover

Package 32.4 gives the native 3D ear a warmer, more human Bloomé presentation without changing its geometry or coordinates.

## Presentation changes

- Applied a warm natural skin colour through the runtime material API.
- Removed metallic appearance and introduced soft editorial roughness.
- Added restrained skin-like specular highlights.
- Refined the cream and blush studio environment for clearer fold depth.
- Increased visual separation between the ear and burgundy markers.
- Softened translucent area fills while retaining clear outlines.

## Preserved baselines

- Ear 1 geometry remains byte-for-byte unchanged.
- Beta 1B.10 coordinates remain byte-for-byte unchanged.
- Camera focus, marker placement, mobile overlay behavior, and attribution remain unchanged.
