# Package 28 — Full Map + Point Detail Polish

Base: Package 27 Condition Page Polish + Depuffing.

## Full Ear Map
- Cleaner centered hero
- 30-point map summary
- Refined search + category toolbar
- Map search now uses the Package 26 fuzzy/token search engine
- Selected-point badge on the map
- Point number + reference code shown in the information panel
- Clearer Location / Traditional Use / Gentle Stimulation hierarchy
- Related-guide count
- Previous / Next point controls
- Point directory cards now show approved map number and reference code
- Improved desktop sticky information panel
- Improved mobile stacking

## Point Detail pages
- Every mapped point now gets its own visual ear preview
- The preview uses the same approved master coordinate used by the full map
- Point number, category and reference code are surfaced clearly
- Location / Traditional Use / Gentle Stimulation / Caution are easier to scan
- Related wellness guides are shown as cards
- Related guides are now derived from the current condition library as well as
  legacy point links. This means newer guides such as Depuffing can appear
  automatically without changing the point-coordinate database.
- Previous / Next navigation across the 30-point master order
- Clear link back to the full interactive map
- Mobile detail layout refined

## Important

- any point x/y position
- the ear illustration
- the 20 condition combinations
- the 30-point acupoint source data
