# Bloomé Guide Package 6.3 — Clean Ear Illustration

## Illustration direction

Use the selected Option 1 ear only.

Keep:
- clean anatomical ear line art
- warm brown outline
- minimal internal ear details
- soft premium educational feel

Remove:
- leaves
- stems
- botanical decoration
- surrounding ornaments
- decorative background elements

## Usage rules

Homepage:
- complete ear visible
- no cropping
- calm breathing space

Condition pages:
- complete ear visible
- markers placed on top
- ear is a map canvas, not a hero image

Mobile:
- entire ear should remain recognisable without zooming.
