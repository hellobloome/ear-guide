# 3D Model Attribution

This Bloomé viewer uses a prepared mesh derived from **“Ear Set”** by **alexlashko**:

https://sketchfab.com/3d-models/ear-set-02a919413aa84e9ea47622a2c8e45864

The original is licensed under **Creative Commons Attribution (CC BY)**. The Ear 1 mesh was extracted from the supplied set, converted for web delivery, and mirrored at the geometry level to match Bloomé’s approved right-ear orientation. Bloomé Guide 1.0 changes presentation, lighting, and viewer styling only; it does not change the approved Ear 1 geometry.
